# 影视提示词写作

以“风格与画面基准 → 主体及环境 → 分时段动作 → 镜头与光影 → 声音”为可调整骨架。具体细节优先于“震撼、电影级、无AI感”等口号。
有参考资产时，编号识别对象，图片锁定外观，文字描述动作、机位、受力与情绪；无参考时补足外观信息。

动作写短因果链：起势、接触、反馈、结果，说明谁向哪个方向运动。群体物体描述形态/方向/速度差异与前后景层次，避免只写“无数”。
对白说明说话人、完整台词、情绪及微动作；场景声与BGM标注出现时机，不在未请求时强行加入。
根据项目风格选择线条/色块或材质/体积光，不机械堆叠2D和照片写实。模型时长、提示词限制与音画能力查当前帮助，不固定声称某版本永远支持某上限。
不以“温和化词汇”绕过平台拒绝；确需调整时根据用户目标和服务明确反馈修改内容本身。
