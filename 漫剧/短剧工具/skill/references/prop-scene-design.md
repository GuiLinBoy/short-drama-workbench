# 道具与场景设计

输入资产详情、项目风格与可选参考图，输出各资产 .prompt.txt；实际生图交由 [即梦生成指南](dreamina-generation.md)。

道具：描述轮廓、尺寸、材质、配色、磨损、稳定纹样；默认单主体、白底、无手持人物，展示可辨识结构。场景：描述空间布局、出入口、尺度、地形、建筑材质、光照方向、天气与氛围，比例通常与视频一致，默认无人。

将可移动且需跨镜头复用的关键道具独立登记；不把墙壁、门窗、固定祭坛等环境构件全部强拆。若需要组合场面图，以 usage=composition 标记用途（type 仍为 scene 或 prop），记录包含的资产，不能误用为干净单体图。

参考图包含人物时，提示仅参考环境结构/材质并排除人物。用户要求保留群像时改为场面参考，不一律删除。

箭雨、飞剑群等动态场面优先写入镜头；需要固定阵型参考时独立标记用途。群体描写包含疏密、朝向、前中后景、速度或磨损差异，避免复制粘贴式排列。

验收图片的主体、背景、空间关系、风格及不应出现的人物/道具。把图像失败和提示词完整性分开判断。
