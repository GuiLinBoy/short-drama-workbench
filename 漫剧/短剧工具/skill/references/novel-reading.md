# 长篇小说读取与资产抽取

## 输入与范围

读取用户指定原文及范围。DOC/DOCX/PDF 按需先用 [文档转换指南](document-conversion.md)。按文本字符索引分段，不把字节偏移当字符偏移；不要求读完整部小说才能制作已指定片段。
调用技能根目录下的 scripts/read_novel.py：

```bash
python3 <技能目录>/scripts/read_novel.py 原著.txt --info
python3 <技能目录>/scripts/read_novel.py 原著.txt --start 0 --length 3000
```

`--end` 可限制范围，`--encoding` 可指定编码；不支持的编码报错，不用替换字符静默破坏原文。脚本返回 JSON，content 与 next_start 分开，文件哈希用于识别修改。

## 工作方法

- 按 next_start 连续读取选定范围，批次大小按上下文与章节边界调整。记录已读与已提交进度，未完成的事件允许保留草稿；进度不得越过已持久化的分析。
- 以完整事件链划分故事，保留起因、转折、高潮与结果。场景变化是镜头/场次边界，不自动等于故事结束。篇幅依素材复杂度，不以凑字数替代信息质量。
- 只将当前改编需要且值得保持一致性的角色、场景、道具登记为视觉资产。路人、瞬时特效、动态箭雨等不默认独立出图。
- 普通资产首次登记直接分配编号；多形态交由 [多形态资产规则](asset-management.md)。对每个资产保留原文出处与创作补充的区别。
- 输出大纲、assets.json、资产详情、资产编号表和读取进度。模板见 [输出格式](output-formats.md)。
