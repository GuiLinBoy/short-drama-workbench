# 文字分镜

读取选定故事、资产、项目风格和目标时长。输出每集 文字分镜.txt，并同步 clips.json。

- 按完整动作和情绪节拍拆 clip，不机械凑满平台最大时长。可生成时长范围在实际 CLI 中确认；分镜时序总和与请求时长一致。
- 铺垫、冲突、高潮、结果依故事需要分配；不把固定百分比作为所有题材硬门槛。
- 每个镜头给出资产 ID、景别/机位、朝向与空间关系、动作过程、光影、环境反馈及必要声音。对白标注说话人、原句、语气和动作，预留可说完的时长。
- 将“威压强大”等抽象表达改为衣摆、尘土、身体反应等可见动作；特效写颜色、形态、轨迹及与环境的作用。
- 少量连续运镜通常更容易生成；叙事需要反打或交叉剪辑时可使用，注意轴线，不一律禁止。
- 每条 clip 写是否承接及原因；只有时间、空间、动作连续且确实需要继承画面时设置 continue_from。转场、时间跳跃、重建空间时为 null。
- 先写预期结束/开始状态；生成上游视频后再观察真实尾帧修正承接描述。不要在尚未生图时声称看到了尾帧。

模板见 [分镜格式](storyboard-format.md)。检查时长、资产形态和动作因果后交给 [视频提示词指南](video-prompts.md)。
