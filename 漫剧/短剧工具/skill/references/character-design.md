# 角色参考图设计

输入资产详情、项目风格、版式及可选参考图；输出对应 .prompt.txt。只有用户要求实际生成时才调用 [即梦生成指南](dreamina-generation.md)。

1. 锁定原文与用户明确设定，将参考图的身份信息、风格信息分别使用；冲突以用户指定依据为准。
2. 让发型、轮廓、体态、服饰材质/配色和标识形成辨识度，避免用脸型或体型直接断言善恶。
3. 默认风格化角色设定；2D 用线条、色块与表情，3D 用体积、材质与受光。用户指定真人概念风格时按其要求，不混入相反约束。
4. 默认横版三视图：左面部特写，右正/侧/背全身，比例一致、白色干净背景、无文字水印。角色图比例独立于视频比例；用户要求单视图或其他版式时覆盖默认。
5. 检查实际版式语义，不要求逐字复制一句固定文案。示例见 [提示词模板](character-prompt-template.md)。
6. 可复用基础图默认不带瞬时战斗特效、手持道具、伴生体；若这些是用户明确的固定身体特征或该形态定义，则保留并记录。独立道具交由 [道具场景指南](prop-scene-design.md)。
7. derived 形态优先用来源图片，说明保持项与变化项。图生图传入真实参考图路径，不只在文字中提“参考图片”。
8. 查看生成图片的脸型、服装、全身视角、四肢、背景及跨形态一致性后，才设 approved。
