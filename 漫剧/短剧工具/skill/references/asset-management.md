# 多形态资产管理

- 先查已有注册表，跨集保持编号不变。角色首形态为 C00001-A，后续 B、C…Z、AA；不要为同一角色重复分配基础编号。
- 年龄跨度、持续换装、易容、物种或稳定外观变化可建新形态；表情、轻微破损、淋雨和瞬时特效写镜头状态。
- 道具/场景仅在可复用且结构差异明确时拆新编号，以 source_asset_id 建立关系。
- 记录 independent/derived/new-form。衍生形态生图可使用来源形态参考，锁定脸型、比例等身份特征；视频直接使用当前镜头对应的最终形态图。
- 适用章节允许多个不连续区间；未读到结束处可用 null 表示未确定。旧形态重现时复用旧编号，不强行永久关闭。
- 同一章有多形态时按镜头实际叙事状态选取；优先级仅用于制作排程，不能代替形态判断。
- 同步更新 assets.json、资产详情与可读编号表；检查来源存在、无自引用/循环、每个正式记录均有详情文件。
