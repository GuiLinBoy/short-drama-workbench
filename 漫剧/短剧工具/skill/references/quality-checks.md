# 漫剧质量检查

检查当前阶段，不默认重读全部技能或全部项目。检查标准引用单一 [数据规范](project-schema.md) 和当前生产技能，避免复制一套容易过期的字数/步骤编号要求。

| 阶段 | 阻塞性检查 |
|---|---|
| ingest | 指定原文范围已读取；资产 ID 唯一；详情存在；事实与创作补充分开 |
| design | 风格、身份/形态及所选版式一致；参考图用途明确 |
| storyboard | 时长与时间段一致；引用资产存在；承接来源在前且无循环；对白可容纳 |
| prompts | 与分镜剧情、资产、时长一致；图号和输入附件一一对应 |
| assets | 文件可解码；实际图像身份/衣着/视角/背景正确，不能仅查prompt |
| clips | 时长、分辨率、音轨符合要求；观察首尾及中间抽帧，动作/身份/衔接可用 |
| assemble | 所有clip按顺序完整纳入；整段解码通过；总时长及音画衔接达标 |

机器检查：调用主技能 scripts/validate_project.py --stage plan 或 --stage assets/assemble。它只检查结构与文件，不替代视觉判断。
输出 质量检查报告.txt：阶段、pass/needs_revision/blocked、文件、证据、影响、修正建议、重审范围。建议项与阻塞项分开，不能把“建议篇幅”升级成硬门槛。
默认同一问题最多两轮自动修正；仍失败时保留可用产物和具体阻塞原因，等待新的信息或调整。涉及已提交付费任务时先查状态，不能因质检重试重复提交未知状态任务。
