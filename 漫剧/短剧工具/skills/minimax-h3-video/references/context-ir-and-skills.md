# 提示词优化（Context-IR）与平台 Skill

## Context-IR 是什么

`use_context_ir=true` 时，平台会先用自己的"导演模型"把我们的提示词改写、扩充成更完整的镜头方案，再去生成视频。官方文档强烈建议开启；时长超过 15 秒时**必须**开启。

开启后会多出"提示词优化"这个阶段，状态通常是 `moderating → queued → running → queued → running → succeeded`，等待时间会变长。

**代价**：我们写的内容会被改写。分镜里精心安排的东西（衔接时的站位、动作顺序、台词原文）有可能被改掉或冲淡。所以：

| 情况 | 建议 |
|---|---|
| 一般叙事、打戏、情绪戏 | 开启，并指定对应的 Skill |
| 时长超过 15 秒 | 平台强制开启；本技能不做超过 15 秒的片段 |
| 衔接要求很严格（上一段尾帧的站位、朝向必须接上） | 先开启试生成；如果开头偏离尾帧，再关闭对比 |
| 台词必须一字不差 | 开启时使用"对白表演与人物调度" Skill（它要求保留原台词）；如果仍被改写，就关闭 |

按官方写作结构组织输入便于检查，但不能保证 Context-IR 不改台词或时间线，结果仍须核对。

Context-IR 的开和关哪种效果更好，需要用项目里的真实片段做 A/B 对比，把结论记在项目的 `风格素材.md` 或 `reports/` 里。没有项目证据或明确批准改变时保持本片既定设置。A/B只是待选诊断方案，不自动产生两次生成授权；开关变化后重新prepare并按对应版本送审。

## 官方 Skill（2026-10-31 通过 `h3_task.py skills` 读取）

每次请求只能指定 1 个 `skill_id`，并且必须开启 Context-IR。

| skill_id | 名称 | 核心规则（摘自 Skill 原文） | 漫剧里用在哪 |
|---|---|---|---|
| `official-cinematic-story` | 导演视觉语言 | 把风格形容词落实为景别、角度、镜头感、运镜、光线、色彩、质感；相邻镜头沿用同一套镜头和光线语法；避免"很电影感""漂亮构图"这类空话 | **默认**：一般叙事、建立场景 |
| `official-social-short` | 短剧钩子设计 | 前 1–3 秒必须出现冲突、危险、指控、反转、欲望、震惊或情绪不稳；尽量从动作的后段切入；每个片段要有"钩子 → 升级 → 引向下一段"；大约每 2 秒变一次景别或动作；结尾要把观众拉向下一段 | **每集第 1 个片段**、集尾悬念片段 |
| `official-dialogue-performance-blocking` | 对白表演与人物调度 | 每句台词定好目的、潜台词、情绪走向、身体和面部行为；人物走位要由权力或压力的变化驱动；指定了台词时要保留原句；台词持续时口型要连续可读 | 对话戏、情绪戏、需要对口型的片段 |
| `official-action-choreography-camera-logic` | 动作编排与运镜 | 写清谁进攻、谁反应、动势往哪走、镜头在哪；保持左右方向和视线不乱；每个运镜只服务一个目的；节奏是"定位 → 冲击 → 恢复"交替；变身拆成"开始、扩散、爆发、余波" | 打戏、追逐、变身、施法 |
| `official-product-showcase` | 商业广告心理 | 一个核心卖点、可视化的利益点 | 漫剧不用 |

### 片段类型 → Skill

分镜里给每个片段标注 `类型`，生成视频时按下表选择：

| 类型 | skill_id |
|---|---|
| 钩子（每集开头、集尾悬念） | `official-social-short` |
| 动作（打斗、追逐、变身、施法） | `official-action-choreography-camera-logic` |
| 对白（以台词和表演为主） | `official-dialogue-performance-blocking` |
| 叙事（其余所有） | `official-cinematic-story` |

一个片段同时符合多种类型时（例如边打边说），选**最难做好的那一项**：有台词又必须对口型时选对白，否则选动作。

## 自建 Skill

平台支持创建自己的 Skill（`POST /minimax/v2/skills`，内容不超过 64 KiB；更新时要传全部字段，没传的字段会被清空）。以后可以把"3D 国漫风格基准 + 上面某个官方 Skill 的规则"合成一个项目专用的 Skill。

创建和修改 Skill 属于修改账号配置，需要先征得用户同意，并把 Skill 原文保存在项目里留底。

## 不依赖平台的部分

官方 Skill 里的规则本身就是很好的写作指南。所以即使关闭 Context-IR，也要在自己写的提示词里落实这些规则，具体写法见 [画面与镜头](visual-and-camera.md) 和 [声音](audio.md)。不要指望平台替我们补齐。
