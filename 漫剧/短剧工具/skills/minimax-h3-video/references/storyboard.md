# 分镜：从剧情到 H3 片段

本页规定分镜怎么写，以及怎么把分镜转成 H3 提示词。依据如下：
- 原技能包 `storyboard.md`、`storyboard-format.md`；
- MiniMax 官方 3D 动画短片 skill 的"标准镜头信息表"（<https://github.com/MiniMax-AI/MiniMax-H3/blob/main/skills/3d-animation-short-generator/references/shot-table-spec.md>）；
- 社区漫剧 skill（novel-to-manju、manju-laoli）。

## 1. 切分原则

- **片段（clip）** 是一次 H3 生成，**镜头（shot）** 是片段里的一次切镜。
- **本地当前默认每次4–15整数秒。** 所依据的H3指南采用该范围；CompShare适配器存在16–30秒选项，但实现与质量未核实，不作为默认路径，不能据此宣称所有渠道都只支持15秒。
- **每个片段 1–2 个镜头，最多 3 个。** 切镜越多，人物一致性越差（社区原话"切镜 = 一致性重掷"），官方 3D 短片 skill 也是一个镜头生成一个片段。只是景别、角度的小变化时，用运镜代替切镜。
- **按完整的动作和情绪节拍来切**，不要为了凑满时长硬拉。一个剧情节点可以用两个快切镜头讲完，但不能直接删掉（剧情保真优先，见原技能包）。
- **`duration` 只能是整数秒。** 分镜按整数秒规划；镜头内部的切点可以精确到毫秒（`At 00:03.500`）。
- **一个镜头里最多 3 个重要角色**（有动作或台词的）。
- **需要连续承接时预留稳定片尾**：以动作完成、对白收口和下段所需状态为准，0.8–1.2秒只是规划参考；取景容纳需要核对的人物、手部和道具。独立切镜不强制定格，是否裁掉余量由实际素材决定。

## 2. 片段类型（决定 Skill，也用于检查节奏）

| 类型 | 含义 | H3 Skill |
|---|---|---|
| 钩子 | 每集第一个片段、集尾悬念 | `official-social-short` |
| 动作 | 打斗、追逐、变身、施法 | `official-action-choreography-camera-logic` |
| 对白 | 以台词和表演为主 | `official-dialogue-performance-blocking` |
| 叙事 | 其他 | `official-cinematic-story` |

节奏检查：每集第一个片段必须是"钩子"，前 1–3 秒就要出现冲突、危险、反转或强烈情绪，不能用风景空镜开场。结尾分两种情况：长篇模式（`series`）的集尾片段要留悬念；短片模式（`short`，1–2 分钟的独立故事）的最后一个片段必须收住（反转、揭晓或情绪落点）。默认直接原生 768P 出片，不再额外标注试生成开关。

## 3. 分镜格式（中文，给人审阅；写入 `文字分镜.txt`）

在原技能包格式的基础上增加了这几项：片段类型、空间锚点、承接、逐秒指令、声音轨。

```text
## Clip 3
- 内容概述：林舟拔剑挡下偷袭，剑气震退黑衣人
- 类型：动作
- 时长：8 秒（整数）
- 镜头数：2
- 承接来源：EP001/Clip00002（原因：同一时空，动作连续）
- 参考素材：Clip00002-尾帧、C00001-A、C00003-A、S00002
- 空间锚点：
  - 固定地标：竹林小径（画面中轴）、左侧倒伏的石灯
  - 人物站位：林舟 画面右三分之一，面向左，持剑未出鞘；黑衣人 画面外左侧
  - 离场人物：无
  - 光线基准：右上方暖色斜阳逆光，竹叶阴影，冷色天光补光
- 镜头 1（0–5 秒，中景，镜头固定后轻微右移）：
  - 0–1 秒：承接尾帧，林舟侧耳，衣摆被风掀起；<竹叶沙沙>
  - 1–3 秒：黑衣人从左侧入画突刺；林舟右脚后撤半步，拔剑出鞘横挡；<金属撞击、火星>
  - 3–5 秒：剑身相抵，林舟手腕一翻发力，黑衣人被震退两步；<低喝>
- 镜头 2（5–8 秒，切近景，低角度，推镜小幅慢速）：
  - 5–7 秒：林舟剑尖斜指地面，冷视左前方；林舟（S1）冷声：「谁派你来的？」
  - 7–8 秒：定格，林舟保持持剑姿态，黑衣人在画面左边缘半跪
- 声音轨：
  - 台词（类型：对白 / 画外对白 / OS / 旁白）：
    - 对白｜林舟（S1）5.2–6.8 秒，冷、低、慢
      - 已批准台词：「谁派你来的？」
      - 配音版：「谁派你来的？」（保持已批准原话，不自行加语气词）
      - 定音台词：是。首次开口视频通过后立即提取、登记、送审真实短样本，并说明约1.6秒的限制；是否另选样本按实际试听与已有审核处理，不自动顺延或另开生成。
  - 音效：1–3 秒拔剑出鞘与金属撞击；3–5 秒布料猎响、脚步滑退
  - 环境：竹林风声持续
  - 配乐：无（后期统一）
- 结束状态（预计）：林舟画面右侧持剑，黑衣人左边缘半跪，二人对视
```

### 逐秒指令的五个要素

关键节拍覆盖下面五项；按动作和声音变化划分时间区间，不强制每秒重复填写。需要精确控制时，再细化关键切点：

1. 动作、姿态、表情
2. 镜头运动
3. 空间位置：人在哪、手里拿着什么、画面里有哪个地标
4. 声音提示：台词、音效、呼吸，或者"静音"
5. 交接：这一秒结束时定下的状态，也就是下一秒的起点

## 4. 承接（片段之间）

每段都执行 [状态读取与三项衔接核对](../../../tools/SHOT_CONTEXT.md)，包括独立切镜。三项内容并入既有内部复核；字段、证据及版本变化处理由该文档统一定义。

- 只有时间、空间、动作都连续，并且确实需要继承画面时，才设置 `continue_from`（原规则）。转场、时间跳跃、重新交代空间时，不承接。
- **上一段的结束状态 = 下一段的开始状态**：站位、朝向、手里的道具、视线、光线。不连续的地方要在分镜里写明，例如"硬切，时间跳过两小时"。
- **离场人物也要跟踪**：上一段在场、这一段不在画面里的人物，要写清他在画外的位置和离开的原因，至少写一段（官方规则）。
- 上一段还没生成时，只写"预计结束状态"。写提示词时，依赖尾帧的两句用 `{{承接定义：…}}` 和 `{{承接开场：…}}` 标出来。生成完成、抽出尾帧后，由**摄影看着真实的尾帧**，用 `set-continuity` 只改这两句（见 [接口与任务](api-and-tasks.md)），不能假装已经看到了画面。

## 4b. 旁白预留

旁白在后期配音，但要在片段里留出时间：按**约每秒 4 字**预留，并写清从第几秒开始。剪辑配好旁白后会写入实际时长 `narration_duration`；超出预留的，由编剧调整这个片段的分镜和提示词。

## 5. 转成 H3 提示词

1. 选模式：人物参考通常用全参考六段式；严格首帧用I2VA，不能混用素材槽。全参考中的尾帧只作开场状态锚点，不保证严格首帧，见 [模式与准备核对](mode-and-preflight.md)。
2. 把分镜组织成**中文**正文，保留技术字段、标签和切镜时间语法：
   - 风格句原样复用；
   - "空间锚点"对应 `subject_definitions` 里的特征和 `[Shot 1]` 的开场构图；
   - 逐秒指令合并成每个镜头里的连续动作描述，按时间顺序写，保留关键时间点（例如 `in the final second`）；
   - 台词按 [声音](audio.md) 的格式写，原文中文保留在 `<d>[Chinese] …</d>` 里；
   - 镜头 2 起写 `[Shot 2] At 00:05.000, the camera cuts to ...`。
3. 写 `overall_soundscape`（环境声和动作声）；`non_diegetic_music` 写 `N/A`。
4. 需要连续承接时写最后的保持状态：“最后一秒，人物保持姿态和站位，动作与运镜停止。”非承接片段不强加定格。
5. 自查（见下）后，通过 `tools/codex_cli.py --project-scope <作品绝对目录> h3 prepare ...` 离线准备。

## 6. 提交前自查清单

- [ ] 时长是 4–15 的整数，各镜头切点严格递增，并且都在时长之内
- [ ] 每个片段 1–3 个镜头；每次切镜都带来新信息
- [ ] 每个镜头最多 3 个重要角色、最多 2 个动作意图、只有 1 种运镜
- [ ] 风格句和项目的风格基准一字不差
- [ ] 参考图各有明确职责，只上传本镜需要的当前形态；不为凑4–5张补无关图，当前图片参考槽最多9张
- [ ] `retention_analysis` 写明主体出现的镜头及保留范围；身份/服装与姿态/构图区分，不把标记当成一致性保证
- [ ] 台词放在 `<d>[Chinese] …</d>` 里，以 `。？！` 结尾，字数没有超过时长限制（语气词也算字数）；不说话的人都写了闭嘴说明
- [ ] 每个说话角色：音色模板已确认的，上传了 `[C编号音色参考]`；还没有模板的，第一次开口处标了"定音台词"
- [ ] 每句台词都标了类型（对白 / 画外对白 / OS / 旁白）；画外对白、OS、旁白期间，画面里每个人都写了闭嘴
- [ ] 每个镜头写了"用这个镜头是为了什么"，镜头写法按 `visual-and-camera.md` §5.1 拆成画面加运动；相邻 3 个片段的景别和运镜不完全相同；单镜超过 4 秒时已标分秒节拍 `[0s-2s]` / `[2s-5s]`
- [ ] 9:16 竖屏优先前后纵深站位与推/拉/微摇运镜，避免大幅横移；底部留 20% 字幕区、顶部留 10% 标识区；无对白强近景/特写已评估走 I2VA 首帧锁构图
- [ ] 按题材配置（`genres/<题材>.md`）的检查项自查；单人镜头写了"画面中只有这一位人物"
- [ ] 非说话动作写安静进行，无对白镜头/停顿写“无人说话，人物双唇闭合”；`overall_soundscape`写具体声源；音色参考约4秒是经验建议，超过本地5秒警告须处理
- [ ] 旁白不由H3生成；对应时间段明确无人说话，预留时长覆盖已存在的真实旁白音轨；尚无音轨只能写估时
- [ ] 进入`<d>`的是已批准配音台词；不擅加语气词，不用连续装饰标点、括号动作或`(laughs)`标签
- [ ] 台词没有出现在引号里；画面里需要出现的文字才放进英文双引号
- [ ] `non_diegetic_music: N/A`（除非项目要求配乐）
- [ ] 承接片段的开头和上一段的真实尾帧一致；需要承接的片段末尾写了定格
- [ ] 打斗没有血腥特写，不出现具名的版权角色（容易被审核拦截，见 [坑与对策](pitfalls.md)）
