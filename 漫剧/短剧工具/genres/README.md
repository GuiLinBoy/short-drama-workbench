# 题材配置

每部作品在 `project.json` 里设 `"genre"`，按对应题材配置承担五岗职责。题材配置规定效果，具体模式和提示词由当前模型技能负责。新稿正文按 OVERRIDES 使用中文，历史英文模板仅供结构参考。

| `genre` | 文件 | 适用 |
|---|---|---|
| `3d-guoman` | [3d-guoman.md](3d-guoman.md) | 3D 风格化国漫：仙侠、玄幻、武侠、古风 |
| `live-action` | [live-action.md](live-action.md) | AI 写实真人剧：现代或古装都可以，追求真人质感 |
| `urban` | [urban.md](urban.md) | 都市剧：**以 `live-action` 为基础**，补充都市题材特有的规则 |

## 规则

- 立项时由总导演问你题材，写进 `project.json` 的 `genre`。没有合适的题材时，选最接近的一个，差异写进 `作品约定.md`。
- **优先顺序**：`作品约定.md` > `project.json`（包括题材配置）> `OVERRIDES.md` > 原技能包。
- 每份题材配置都包含这几项：
  1. 风格句；
  2. 生图模型优先级；
  3. 参考图规格；
  4. 常用镜头；
  5. 动作与表演；
  6. 声音偏好；
  7. 题材特有的检查项；
  8. 素材库能不能用；
  9. 合规要求。
- 新增题材时，按同样的结构写一份，并在上表登记。
- 题材配置里的"推荐"都是**初始建议**。统一验证和实际制作之后，按效果修订，并在文件末尾的修订记录里写明。

## 所有题材共用的规则（不在各题材文件里重复）

- 台词四种类型、两版台词、定音台词、旁白后期、配乐后期、防止乱说话：见 H3 技能 `audio.md` 和设计文档 §8.5。
- 承接、定格、片段 4–15 秒、每段 1–2 个镜头：见 H3 技能 `storyboard.md`。
- 镜头选择：见 [镜头语言手册](../镜头语言手册.md)，各题材文件只写偏好。
- **AI 生成内容标识**：所有要公开发布的作品都要加，见设计文档 §8.8。
