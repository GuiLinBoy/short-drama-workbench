## 一、怎么用

1. 编剧写分镜时，每个镜头注明**用这个镜头是为了什么**，例如"仰拍：表现他压人一头"。
2. 先按"剧情功能"（第二节）选方案，再到第三、四节查术语和写法。
3. **镜头名字只是给人看的。写进提示词时，要拆成"画面里先出现什么 + 怎么构图 + 镜头怎么动"**。社区实测表明，只写镜头名字大多不起作用（例如只写 `cowboy shot`）。
4. 每段视频只有 1–2 个镜头，所以**正反打这类多镜头手法，要拆到相邻的几个片段里**，在分镜阶段统一规划。
5. 一集里的镜头要有变化：相邻的 3 个片段不要用同一种景别加同一种运镜。

## 二、按剧情功能选镜头（分题材）

| 剧情功能 | 3D 国漫 | 写实真人、都市剧 |
|---|---|---|
| **开场钩子**（前 1–3 秒） | 冲突动作的特写切入（剑光、碎裂）；或者从剪影里冲出 | 直接切到冲突瞬间：摔门、耳光、文件拍桌；手持近景 |
| **交代场景** | 大远景、航拍、摇臂升起，看到山门、云海 | 全景快速交代空间，或者从细节（门牌、桌上的照片）拉出 |
| **压迫、强者登场** | 低角度仰拍、逆光剪影、缓慢推近 | 低角度、对称构图；人物从画外走入前景 |
| **对峙、谈判** | 两人分站画面两侧的双人镜头，过肩 | **过肩正反打**（拆成相邻片段）；反应镜头 |
| **对话** | 双人镜头为主，穿插近景 | 过肩加近景交替；说话人脸要够大（中近景以上） |
| **孤独、失落** | 大远景，人物在画面一角，背影 | 高角度俯拍、框中框（门框、窗框）、留白 |
| **揭示、发现** | 从遮挡物后移出（柱子、树）；摇镜带出 | 焦点转移（从前景物件转到人物）；后拉揭示 |
| **情绪爆发** | 特写到大特写，配合环境异象（风起、光爆） | 近景、浅景深、缓慢推近；手持轻晃 |
| **不安、悬疑** | 荷兰角、前景遮挡、窥视的主观视角 | 手持、前景遮挡、门缝窥视、荷兰角 |
| **动作高潮** | 跟拍、横移、半圈环绕；冲击时轻微震动 | 手持跟拍、快速切换（拆成短片段），运镜简单稳定 |
| **回忆、梦境** | 柔光、慢动作、偏暖或偏冷的色调 | 同左；转场需要叠化时要明确提出 |
| **温情、亲密** | 近景、暖色侧光、固定镜头 | 双人镜头、近景、浅景深、极慢推近 |
| **结尾悬念 / 收尾** | 拉远到大远景，或者定格在关键物件的特写 | 停在一个人的反应镜头上；或者插入关键道具的特写 |

## 三、术语表

### 3.1 景别
| 中文 | 取景 | 注意 |
|---|---|---|
| 大特写 | 眼睛、嘴、手指 | 【官方】 |
| 特写 | 整张脸 | 【官方】 |
| 近景 | 胸部以上 | 【官方】；**全参考模式下开场容易偏宽**，见第五节 |
| 中景 | 腰部以上 | 【官方】 |
| 七分身（牛仔镜头） | 大腿中部以上，能看到腰间的兵器或手 | 只写名字【失败】；要写成"从大腿中部以上取景" |
| 全景 | 全身 | 【官方】 |
| 远景 | 人物加环境 | 【官方】 |
| 大远景 | 环境为主，人很小 | 【官方】；人脸太小容易崩，远景人物用背影或侧背 |

### 3.2 机位关系
| 中文 | 画面 | 写法要点 | 可信度 |
|---|---|---|---|
| **过肩** | A 的肩膀虚化在前景，对面的 B 清楚 | **先写前景的肩膀，再写对面的人**，写反了不成立 | 【实测】最稳的关系机位 |
| **过肩推近** | 过肩开场，慢慢推到近景 | 先写过肩，再写"机位缓慢前推，焦距全程锁定在同一档位" | 【部分】能推到中近景，到不了脸部特写 |
| **过腰（过臀）** | 机位在 A 的腰侧，A 的手、兵器在前景 | 先写前景的腰、手或兵器，再写对面的人 | 【未测】 |
| **正反打** | 两个镜头交替拍对话双方 | 一段里硬切能做到，但切点会提前 1–2.5 秒；**建议拆成相邻片段**，每段一个机位 | 【实测】 |
| **双人镜头** | 两人同时在画面里 | **必须写清两人的距离、谁在里侧**，否则位置随机 | 【实测】 |
| **三人镜头** | 三人同时在画面里 | 写清每个人的位置；最多 3 个重要角色 | 【未测】 |
| **主观视角** | 从角色的眼睛看出去 | 角色本人不入画；走动写在剧情里 | 【官方】【部分】（有人反馈看不出是谁的视角） |
| **反应镜头** | 听者的表情 | 写清表情变化的过程 | 通用 |
| **插入镜头** | 物件特写 | 写清物件的材质、状态和光线 | 通用 |
| **建立镜头** | 交代场景全貌 | 环境用一句话描述，不要逐项列出 | 通用 |

### 3.3 机位高度与角度
| 中文 | 效果 | 可信度 |
|---|---|---|
| 平视 | 中性、客观 | 【官方】 |
| 低角度仰拍 | 强大、压迫 | 【官方】 |
| 高角度俯拍 | 弱小、被支配 | 【官方】 |
| 顶拍（上帝视角） | 全局、宿命感 | 【实测】 |
| 虫视（贴地仰拍） | 极度压迫、巨物 | 【未测】 |
| 荷兰角（倾斜） | 不安、失衡 | 【实测】；写成静态的倾斜方向，不要写成运动 |

### 3.4 运镜（官方 12 种加组合）
| 中文 | 写法要点 | 可信度 |
|---|---|---|
| 推 / 拉 | 写起止景别，加"焦距全程锁定"，说明是机位在动 | 【官方】 |
| 变焦推 / 拉 | 写"机位位置固定，画面变化来自变焦" | 【官方】 |
| 摇（左右） | 写摇的方向和幅度，**不要写焦距** | 【官方】 |
| 俯仰（上下） | 同上 | 【官方】 |
| 横移 | 写侧移方向、末尾停在哪，加"镜头朝向全程锁定"；不要写"视线始终锁定主体"（会变成环绕） | 【官方】 |
| 升降 | 写升或降，加"镜头姿态全程水平"（否则会变成升加摇） | 【官方】 |
| 环绕 | **半圈稳定**；整圈要同时写圈数和起止时间，否则经常转不完 | 半圈【实测】，整圈【部分】 |
| 跟拍 | 写跟随谁、相对距离 | 【官方】 |
| 固定 | 写"机位位置全程固定在同一点" | 【官方】 |
| 手持晃动 | 轻微或强烈 | 【官方】 |
| 横滚 | 必须写方向 | 【官方】 |
| 希区柯克变焦 | 机位前推的同时变焦拉远，人物大小不变，背景被拉远 | 【实测】 |
| 急推 | 速度不受控制，模型会自己决定快慢 | 【部分】 |
| 甩镜 | 写"机位固定，只有镜头朝向在甩动"，过程中有横向动态模糊，最后停在第二个主体上 | 【实测】 |
| 焦点转移 | 写清开始时谁清楚、谁虚，在什么动作之后焦点转到谁 | 【实测】 |
| 摇臂升起 | 升起并俯视全景 | 【实测】 |
| 子弹时间 | — | 【失败】，不要用 |

### 3.5 构图与光线
| 中文 | 作用 | 写法要点 |
|---|---|---|
| 前景遮挡 / 揭示 | 窥视、层次 | **先写前景遮挡物**，开场画面里只有遮挡物 |
| 框中框 | 困住、隔阂 | 写清门框、窗框的位置 |
| 剪影 | 神秘、登场 | 写清逆光的光源方向 |
| 倒影镜头 | 内心、双面 | 写清倒影出现在哪个表面上 |
| 浅景深 | 突出主体 | 写清背景是什么、虚化到什么程度 |
| 对称构图 | 秩序、权力 | 写清对称的中轴 |
| 三分法 | 平衡 | 写清人物在画面左三分之一还是右三分之一 |

## 四、写法纪律（所有视频模型通用的原则，H3 的具体写法见 H3 技能）

1. **写成正面的描述，不写否定句**：例如写"机位位置全程固定在同一点"，不写"机位不动"。否定句可能把运镜压掉，或者反而让被提到的东西出现。
2. **画面里先出现的东西写在前面**：遮挡、过肩、揭示、甩镜都要先写最先出现的元素。
3. **每种运镜只写它自己的变量**：摇镜不写焦距，横移不写"锁定主体"。
4. **环境用一句话描述，不要逐项列出**：列清单会让画面被推宽。
5. **时间点只是参考，会漂移约 ±1 秒**：关键动作要靠"先……然后……"的次序来保证。
6. **只写镜头名字不起作用**，焦段（8mm、50mm）、相机型号也基本不起作用；要写画面和运动。
7. **防止复制出第二个人**：竖屏下做横向运镜，模型容易复制一个人来补位，单人镜头要写明"画面中自始至终只有这一位人物"。
8. **效果不好时，先换随机种子，再改写提示词**。

## 五、已知限制（在统一验证里复测）

- **全参考模式下，开场景别偏宽**：社区引用的官方测试矩阵里，"中景及更近"的开场取景命中 0/51，文字上的约束都没用；能锁住取景的只有首帧模式。是否影响我们用的接口，要实测（都市剧对话约 4 段）。
- **场景参考图会削弱运镜**：加了背景参考图，运镜幅度大约减半。需要大幅运镜的片段，可以考虑不上传场景图，或者把运镜写得更强。
- 社区实测**都是本地开源版**：我们用的接口开着提示词优化，结果可能更好，也可能不同。
