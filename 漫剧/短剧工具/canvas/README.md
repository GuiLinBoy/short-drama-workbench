**审核操作补齐（2026-11-08）：** 新增「取消暂缓，恢复待确认」及审核状态筛选，支持批量取消并保留历史。自动勾选仅含可确认的待确认项；隐藏选择禁止提交，恢复筛选可准确定位且保留未保存意见。取消暂缓不自动通过或恢复制作。

**批量通知更新（2026-11-08）：** 单项决定保存后，点击「本批审核完成，通知总导演」一次入队。页面区分待投递、投递中、已投递和总导演已接收；只有活动统一调度使用真实会话工具后才推进状态，离线留队，未知不自动重发。当前实际投递未启用，真实制作继续暂停。见 [通知接入说明](../tools/CANVAS_NOTIFICATION.md)。

新版本详情及送审格式见 [画布审核工作流](../tools/CANVAS_REVIEW.md)。以下「只读」描述适用于生产清单、账本、媒体及原保留版本；新版本唯一写入为专用审核记录，不提供生成/重试/改账本/公开发布入口。Mac旧保留ZIP仍保持原样，新版部署需连同 `../tools/canvas_review.py` 一起准备。

本机运行的制作与审核工作台。生产清单、账本和素材只读，仅追加用户审核记录。独立放在 `canvas/`，读取上两级 `漫剧/` 中的作品文件，不导入制作脚本，不调度会话，不连接 H3、IndexTTS 或 NexorAI。

## 启动

当前工作区已经安装依赖并生成 `dist/`。双击本目录的 **start.cmd**，保持窗口打开，再用浏览器访问 **http://127.0.0.1:8778/**。按 Ctrl+C 停止。`start-review.cmd` 是同一启动入口的兼容别名。

也可以在本目录运行：

```powershell
python -I -X utf8 server.py
```

需要 Python 3.10 或以上。正式画布端口固定8778；已启动时直接访问该地址，否则处理占用后重试。服务固定绑定 `127.0.0.1`，不提供局域网或公网入口。仅独立测试数据的临时预览可明确使用 `--preview --data-root <隔离数据根> --port <测试端口>`，不作为正式入口。

## 首次安装、重建

构建需要 Node.js 20 或以上以及 npm。在本目录执行以下命令，npm 配置独立于个人配置，不需要登录：

```powershell
$env:NPM_CONFIG_USERCONFIG = Join-Path $PWD '.config/npm-user.conf'
$env:NPM_CONFIG_GLOBALCONFIG = Join-Path $PWD '.config/npm-global.conf'
npm ci --ignore-scripts --no-audit --no-fund
npm run build
npm start
```

修改前端源码后需要重新 `npm run build`，然后刷新浏览器。修改 `server.py` 后需要停止并重新启动服务。没有另一个 Vite 开发服务，避免代理与本机来源限制不一致。

## 数据解释

- 默认只扫描 `漫剧/作品/` 的直接子目录。`作品清单.json` 缺失时自动发现，不替工具建立登记表；清单存在时只用同名记录补充阶段、状态、等待事项，不接受清单指定的外部目录。
- 读取固定清单 `project.json`、`assets.json`、`clips.json`、可选 `voices.json`，以及预算、任务状态、事件日志、成片 validation 报告。文本与素材只允许使用这些清单已引用的本地文件。
- `generated` 显示为待审；只有清单明确的 `approved` 才计入通过数量。流水线文件就绪、视频存在和解码报告都不代表人工验收通过。岗位列表不表示 bot 正在运行。
- 样例作品中的小尺寸 PNG 标记为占位图；明确标记 `data_kind: simulation` 的作品显示为模拟数据。其余作品显示为本地作品，不自动宣称是真实生产数据。
- 2026-11-05 的“验收-第4组 / 验收-调试”IndexTTS 四条旧记录明确标为历史模拟。全局账本逐条展示，**不会把 charge、settle、refund 相加当作总消费**。
- 预算 `used` 是本地批次记账，可能同时包含已用费用与未结算预占；积分和出图张数分别展示。预算不是新消费授权。账户余额始终显示“未查询”，不用历史余额推断实时余额。
- H3 与 IndexTTS 占用共享槽位，NexorAI 单独统计；包含提交占位、排队、结果不明等活动状态。超过 60 分钟的活动任务会突出等待时间。仅反映本地状态，不能代替平台核对。
- 文件变化通过本机 SSE 推送修订，约两秒检查一次；断线自动重连，另有 30 秒读取兜底和手动刷新。读取出错时保留上次结果并提示，不把损坏数据标为完成。

## 边界与验证

服务提供 GET/HEAD 和专用 POST /api/reviews。审核写入仅限本机精确同源及会话令牌校验；其他写方法返回405。API 与素材限制本机同源，不开放 CORS；只有静态首页允许从书签或浏览器扩展正常导航进入。路径解析会阻止越界、绝对路径、远程 URL 和私密文件名；素材通过已登记的不透明 ID 访问。文本作为 JSON 返回并由 React 按文本显示，限制脚本与外部连接来源。不读取密钥文件、环境变量或平台凭据。

读取有界：单份 JSON 最大 2 MB；单份日志读取尾部 2 MB / 2000 行；每作品最多投影 500 项资产、片段、任务和 30 份事件日志，时间线保留最近 300 条。超过这些规模需要继续扩展并验收。目录扫描与素材解析仍需真实项目规模验证。

```powershell
npm run build
npm run test:local
npm run test:canvas
```

测试在 `canvas/.qa/` 创建隔离数据，不改写作品。浏览器检查使用实际样例数据和另一个隔离的模拟片场；本地测试视频由 FFmpeg 合成。详见 [首版验收记录](验收记录.md) 与 [A 风格改造验收](A风格改造验收.md)。

新增操作详见 [画布操作增强验收](画布操作增强验收.md)。一键整理不会自动覆盖已保存坐标；撤销保留当前范围最近 12 步，刷新或切换范围后清空撤销历史。

本版本完成观察与本地用户审核入口。真实 bot 全链、生产素材审核、平台对账、计费/并发/字幕/经验工具的验收仍属于原制作项目，不能因画布测试通过而认定全项目可用于生产。
